# 글가람

중학교 2학년 국어 복합양식 글쓰기 활동을 위한 웹 프로토타입입니다.

## 실행

Node.js 22 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
cd /workspace/4main
npm start
```

기본 포트는 3000이며 `PORT`로 바꿀 수 있습니다. 검증은 `npm test`로 실행합니다.

## 학생 활동

주제·목적·유형 정하기 → 학습 자료 선택 → 활용 내용·출처 기록 → 개요 작성 → 초안 편집 및 HTML 내려받기 또는 인쇄/PDF.

자료 추천은 서버 연결 시 실제 AI 웹 검색을 사용하며, 미연결 상태에서는 학습용 예시를 제공합니다. 초안은 학생이 입력한 개요와 자료 내용을 연결해 생성합니다. 실제 통계·인터뷰·사진은 학생이 조사하고 출처와 이용 조건을 확인해야 합니다.

작업은 브라우저 localStorage에 저장됩니다. 교사 제출함, 계정, 기기 간 동기화는 포함되지 않습니다. 공용 기기에서는 작업을 내려받고 ‘내 작업 지우기’를 사용하세요.

## 실제 AI 자료 검색 배포

GitHub Pages는 정적 파일만 실행하므로 API는 실행할 수 없습니다. 가장 간단한 방법은 **Vercel에서 이 저장소 전체를 배포**하는 것입니다. 서버리스 함수 `api/resources.js`가 검색을 처리하며, 브라우저에는 키가 전달되지 않습니다.

1. Vercel에서 Add New → Project → 이 GitHub 저장소 Import.
2. Framework Preset은 Other, Root Directory는 저장소 루트. 별도 빌드 명령이나 패키지 설치는 필요 없습니다.
3. Project Settings → Environment Variables에 `WRITING_AI_KEY`를 추가합니다. 값은 OpenAI API 키이며 채팅이나 저장소에 넣지 않습니다. ChatGPT 구독과 API 사용료는 별도입니다.
4. Deploy 후 제공되는 Vercel 주소에서 글쓰기 계획을 입력합니다. 자료 탐색으로 넘어가면 자동 검색합니다. 환경 변수를 나중에 추가했다면 Redeploy합니다.
5. 선택 사항: `WRITING_AI_MODEL` 기본값 `gpt-4.1-mini`. 웹 검색 도구를 지원하는 모델을 사용해야 합니다.

기존 GitHub Pages 주소를 유지하려면 `config.js`의 `GEULGARAM_API_BASE`를 Vercel 서버 주소(HTTPS, 경로 없이)로 지정하고, 서버에는 `ALLOWED_ORIGIN=https://dreamoflondonbridge-netizen.github.io`를 설정합니다. 서버를 연결하지 않은 GitHub Pages 화면은 AI 검색 연결 안내와 기존 예시 자료를 보여줍니다.

로컬 실행은 Node 22 이상에서 `node --env-file=.env server.mjs`로 할 수 있습니다. `.env.example`을 참고하되 실제 값은 무시되는 `.env`에만 보관하세요.

검색은 OpenAI Responses API의 웹 검색 도구를 사용합니다. 검색 도구가 반환한 출처 또는 인용 URL과 정확히 일치하는 추천만 최대 6개 표시합니다. 출처 일치는 내용의 정확성·최신성·저작권 검증을 보장하지 않으므로 학생이 원문을 확인해야 합니다. 확인하지 못한 날짜는 표시하지 않습니다. 원문 이미지를 자동 복제하지 않습니다.

동일 주제 검색은 서버 인스턴스 메모리에 1시간 캐시됩니다. 인스턴스별 동시 검색 3개, 연결 주소별 분당 6개로 요청을 제한하지만 서버리스 인스턴스 간 공유 제한은 아닙니다. 공개 수업 운영 전에는 Vercel 방화벽의 요청 제한과 OpenAI 프로젝트의 사용량 한도·알림을 설정하세요. 학생 이름이나 연락처를 주제에 입력하지 않도록 지도해 주세요. API 요청에는 주제·목적·유형만 전달하며 학생 초안·메모는 보내지 않습니다.

현재 자동화 테스트는 모의 검색 응답으로 출처 필터·오류·워크플로를 검증합니다. 실제 유료 API 호출 및 공개 서버 배포 검증은 API 키와 호스팅 연결 후 별도로 필요합니다.
