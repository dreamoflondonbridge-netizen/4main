# 글가람

중학교 2학년 국어 복합양식 글쓰기 활동을 위한 웹사이트입니다. 유료 API나 별도 서버 연결 없이 GitHub Pages에서 동작합니다.

## 학생 활동

1. 주제·목적·글 유형을 정합니다.
2. 자료 탐색에서 네이버·구글 검색을 새 탭으로 열고 자료를 직접 찾습니다.
3. 자료 제목, 원문 링크, 출처, 핵심 내용과 발행일(선택)을 입력해 나의 자료함에 가져옵니다. 직접 만든 사진·그림은 링크 없이도 첨부할 수 있습니다.
4. 자료함에서 사용할 자료를 선택하고 활용 내용·출처·배치 위치를 정합니다.
5. 처음·가운데·끝 개요를 작성한 후 만들어진 초안을 직접 고칩니다.
6. 글과 첨부 이미지를 HTML 파일로 내려받거나 인쇄/PDF로 저장합니다.

사진·도표는 PNG/JPG/WebP 파일(각 1MB 이하)을 첨부할 수 있습니다. 링크를 입력하면 원문으로 이동할 수 있으며 외부 페이지 내용을 자동 수집하지는 않습니다. 이미지 이용 조건과 출처는 직접 확인해야 합니다. 사진·그림을 포함할 때는 자료 유형을 그림·도식 또는 비교표로 선택합니다.

## 저장 및 배포

작업은 브라우저 localStorage에 저장됩니다. 첨부 이미지가 많으면 브라우저 용량 제한으로 자동 저장이 실패할 수 있으며 이때 화면 상단에 안내합니다. 작업은 글 내려받기로 별도 보관하세요. 공용 기기에서는 내려받은 후 ‘내 작업 지우기’를 사용하세요. 교사 제출함·계정·기기 간 동기화는 포함되지 않습니다.

기존 GitHub Pages의 main / 루트 또는 Static HTML 워크플로를 그대로 사용합니다. API 키, Vercel, OpenAI 연결이 필요하지 않습니다. API 검색 코드는 제거했습니다. 예전 버전에서 선택한 자료와 작성 메모는 처음 열 때 새 자료함으로 옮겨 보존합니다.

## 로컬 실행 및 검증

Node.js 22 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
npm start
npm test
```

기본 포트는 3000이며 PORT로 변경할 수 있습니다. 자동화 검증은 자료 추가·수정·삭제, 출처 및 메모 보존, 잘못된 링크 차단, 이미지의 완성 글 포함, 초안 작성 흐름을 확인합니다.
